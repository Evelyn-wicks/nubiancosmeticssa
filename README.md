Project overview
 Project Overview

Nubian Cosmetics SA is a multi-page website designed to showcase a proudly South African beauty brand that celebrates inclusivity, sustainability, and luxury. The project was developed as part of the Web Design module, with the goal of creating a professional, rubric-compliant site that demonstrates technical skill in HTML, CSS, and responsive design.

The website highlights the brand’s mission to empower individuals through beauty products that embrace diverse skin tones and natural aesthetics. It integrates storytelling, product presentation, and blog tutorials to engage users while maintaining a clean, modern layout.

Objectives
- Build a **multi-page website** (Home, About, Shop, Blog, Contact, Location, Enquiry).
- Ensure **rubric compliance** with proper folder structure, image referencing, and semantic HTML.
- Apply **Visual Design & Styling (VDS)** principles using a consistent earthy colour palette (Café Noir, Kombu Green, Moss Green, Tan, Bone).
- Incorporate **responsive design** for mobile and desktop users.
- Demonstrate **payment integration awareness** (PayFast/Mobicred demo buttons).
- Provide **educational blog content** (skin tutorials, sustainability, brand story).

 Key Features
- **Homepage**: Hero banner with catchphrase “Glow with Confidence,” featured products, and blog previews.
- **About Page**: Brand backstory celebrating African heritage and inclusivity.
- **Shop Page**: Product cards with demo PayFast/Mobicred payment buttons.
- **Blog Page**: Creative tutorials (Morning Glow Routine, Evening Reset Ritual, DIY Masks, Sustainability in Beauty).
- **Contact & Enquiry Pages**: Forms for customer engagement and feedback.
- **Location Page**: Map and address details for local presence.

 Technologies Used
- HTML5 for structure
- CSS3 (Flexbox, Grid, Responsive Design)
- GitHub for version control and deployment
- PayFast/Mobicred integration (demo setup)

Target Audience
South African consumers seeking inclusive, sustainable, and premium beauty products, with a focus on young professionals and students who value authenticity and eco-consciousness.

Project Duration
The project was completed over a period of **3 weeks**:
- **Week 1**: Planning, wireframes, and folder structure setup.
- **Week 2**: HTML skeleton creation and CSS styling (colour palette, responsive layout).
- **Week 3**: Content integration (images, blog tutorials, payment demo) and final rubric alignment.

 Purpose
The purpose of this project is to:
- Demonstrate competency in web design principles and responsive coding.
- Showcase Nubian Cosmetics SA as a brand that celebrates inclusivity and sustainability.
- Provide a professional, rubric-compliant multi-page website for academic assessment.
- Educate users through creative blog tutorials (skin routines, DIY masks, sustainability tips).
- Simulate e-commerce functionality with demo payment integration (PayFast/Mobicred).

Usability

The Nubian Cosmetics SA website was designed with responsive principles to ensure accessibility across multiple devices:

- **Smartphones**: Content stacks vertically, images resize to fit smaller screens, and navigation collapses into a mobile-friendly menu.
- **Tablets (iPad)**: Balanced layout with side-by-side text and images, ensuring readability and smooth interaction.
- **Laptops/Desktop**: Full-width hero banners, multi-column product grids, and expanded navigation for a professional browsing experience.

This responsiveness was achieved using CSS Flexbox and Grid, combined with `max-width: 100%` and `height: auto` rules for images.
